# Маршрут для дизайнера

Курс рассчитан на путь «с нуля до junior frontend» — это много, и не каждому дизайнеру нужно идти весь путь. Ниже три сценария с разными целями и разными точками выхода. Выбери тот, что ближе, и читай только то, что в твоём столбце.

> Если сомневаешься — начни со сценария **B** (свои сайты для портфолио). Это самая частая мотивация у дизайнеров и хороший компромисс: ощутимый практический результат без необходимости лезть в тяжёлую инженерию.

## Три сценария

| Цель | Что получишь | Сколько курса нужно |
|---|---|---|
| **A. Лучше понимать разработчиков** | Перестаёшь спорить вслепую на созвонах. Знаешь, что в макете «дёшево», а что «дорого». Отдаёшь Figma-файлы, к которым у разработчиков меньше вопросов. | ≈25–30% курса, 2–3 недели в комфортном темпе |
| **B. Делать свои сайты для портфолио и фриланса** | Можешь сам сверстать лендинг, кейс из портфолио, простой сайт-визитку, задеплоить и дать живую ссылку. | ≈50% курса, 2–3 месяца |
| **C. Стать junior frontend с дизайнерским бэкграундом** | Полноценный переход в профессию. Дизайнерский опыт становится конкурентным преимуществом, а не балластом. | 100% курса, 6–10 месяцев |

---

## Сценарий A — «Понимать разработчиков»

**Кому подходит:** ты не собираешься верстать сам и не хочешь становиться разработчиком, но устал от ситуаций «я не знаю, можно ли так» и «они опять сказали “это сложно”, а я не понимаю, почему».

**Что читать (по порядку):**

| Модуль | Что взять | Что пропустить |
|---|---|---|
| **00 — Установка** | Только VS Code и терминал-минимум, чтобы открывать файлы и иногда запускать одну команду. Node.js не нужен. | Регистрация в GitHub — необязательна, но не помешает. |
| **01 — Setup** | [[01.1-Инструменты]], [[01.4-Контекст-для-дизайнеров]], [[01.5-Как-макет-становится-сайтом]] | [[01.3-DevTools-минимум]] — пробежать по диагонали |
| **02 — HTML** | Только обзор + урок про семантику. Понять, из чего вообще состоит страница. | Формы, аксессибилити в деталях |
| **03 — CSS база** | [[03.4-Box-model-и-позиционирование]], [[03.5-Flexbox]], [[03.6-Grid-и-адаптив]] — основа разговоров про вёрстку. | Селекторы и каскад — обзорно, без зубрёжки |
| **04 — CSS продвинутый** | Только обзор: что такое Tailwind и зачем нужны CSS-переменные | Препроцессоры, transitions в деталях |
| **07 — Веб-архитектура** | [[07-Веб-архитектура/00-Обзор-модуля]] обзорно — что такое API, REST, почему данные грузятся не мгновенно. | CORS, JWT, хранилища |
| **09 — React база** | Только [[09-React-база/00-Обзор-модуля]] и [[09.1-JSX-и-компоненты]] — понять, что такое компонент в коде и почему он похож на компонент в Figma. | Хуки, события, формы |

**Где остановиться:** после обзорного знакомства с React. Дальше — уже инженерия, она тебе не нужна.

**Чего НЕ нужно вообще:** модули 05, 06 (JavaScript глубоко), 10 (React-экосистема), 11 (TypeScript), 12 (build tools), 13 (Next.js + backend), 14 (деплой и production-инженерия).

**Финальный маркер успеха:** на следующем созвоне с разработчиком ты задаёшь предметный вопрос вроде «эту секцию проще через Grid или Flexbox?» — и понимаешь ответ.

## Сценарий B — «Свои сайты для портфолио и фриланса»

**Кому подходит:** хочешь сам делать лендинги и одностраничники без зависимости от разработчика. Цель — не профессия фронтендера, а **самостоятельность** на простых проектах.

**Что читать (по порядку):**

| Модуль | Что взять | Что пропустить |
|---|---|---|
| **00 — Установка** | Полностью | — |
| **01 — Setup** | Полностью | — |
| **02 — HTML** | Полностью | — |
| **03 — CSS база** | Полностью | — |
| **04 — CSS продвинутый** | Полностью | — |
| **P1 — Лендинг по Figma** | Сделай **обязательно**. Это твой первый реальный артефакт. | — |
| **08 — Git и DevTools** | Только Git-минимум (commit, push, pull) и базовый DevTools. PR-процесс — обзорно. | Углублённые DevTools |
| **14 — Деплой** | Только Vercel/Netlify-разделы и Core Web Vitals на уровне «как проверить, что сайт быстрый». | App Router-специфика, мониторинг production |

**Дополнительно:** **сделай свой designer-проект** — возьми любую case study со своего behance/dribbble и свёрстай как одностраничник, задеплой, добавь живую ссылку в портфолио. Это даст тебе портфолио-усиление сильнее, чем учебный лендинг.

**Где остановиться:** после P1 и базового деплоя. Свой кейс — третий лендинг — закроет потребность.

**Чего НЕ нужно:** модули 05, 06, 09, 10, 11, 12, 13. JavaScript на этом уровне почти не понадобится — только мелочи вроде «открыть мобильное меню по клику», и для этого хватит копипаста из MDN.

**Финальный маркер успеха:** ты можешь взять Figma-макет (свой или чужой) и за 2–4 дня превратить его в живой сайт по уникальному URL.

> **Совет.** Если хочешь идти этим путём, посмотри также [[01.6-Figma-Dev-Mode-и-плагины]] (если урок уже создан) — он показывает встроенный Dev Mode и плагины-генераторы кода, которые ускоряют верстку в разы.

## Сценарий C — «Junior frontend с дизайнерским бэкграундом»

**Кому подходит:** хочешь сменить профессию или совмещать дизайн и фронтенд (часто — на старте карьеры в продуктовых командах). Цель — оффер junior-разработчика.

**Что читать:** **весь курс**, без сокращений. Модули 05, 06, 09, 10, 11, 12, 13 — обязательны.

**Особенности маршрута для дизайнера:**
- Модули 03–04 (CSS) пройдут быстрее, чем у не-дизайнера, потому что концептуально это твоя территория.
- Модули 05–06 (JavaScript) — самая тяжёлая часть, не пугайся. Аналогий с Figma тут мало, нужно просто пройти.
- Модуль 09 (React) снова станет проще: компоненты, props, состояния — всё это есть в Figma в близких формах.
- На собеседованиях твой дизайнерский опыт — преимущество, особенно для команд, где ценят design-инженерию (design systems, дизайн-разработчики, design-eng роли).

**Финальный маркер успеха:** P3 (fullstack-проект на Next.js) собран и задеплоен, ты прошёл первое техническое собеседование без катастрофы.

## Что ты не теряешь, выбирая короткий маршрут

Курс задумывался как полный путь до junior, но **80% его пользы для дизайнера лежит в первой половине**. Сценарии A и B не «недокурс» — это сознательно скоррелированные срезы под конкретные цели. Если позже захочешь идти дальше, материал в модулях 05+ никуда не денется, и ты вернёшься к нему с готовой базой по HTML/CSS, что облегчит дорогу.
