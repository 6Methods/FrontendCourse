# Массивы как объекты

## Зачем это нужно

В уроке про массивы ты работал с `[1, 2, 3].map()`, `.filter()`, `.length`. Но вот странность: `typeof []` возвращает `"object"`. И `[1, 2, 3]["1"]` даёт `2`. И массивы можно расширять произвольными свойствами: `arr.foo = "bar"`. Это не случайности — **массивы в JavaScript реализованы как объекты** со специальным поведением. Понять эту связь — значит перестать воспринимать массивы и объекты как два разных мира.

> **Опорные концепты:** массивы, объекты, прототипы.

---

## Главное

### Массив = объект с числовыми ключами

```js
const arr = ["a", "b", "c"];

// Под капотом это почти то же самое:
const obj = {
  0: "a",
  1: "b",
  2: "c",
  length: 3
};
```

Доступ `arr[0]` — это `obj["0"]`. Индексы массива — это строковые ключи объекта. Разница в том, что массив:
- автоматически обновляет `length`
- наследует методы от `Array.prototype` (`map`, `filter`, `push`...)
- получает специальное поведение при `JSON.stringify` (квадратные скобки)

**Диаграмма:**
```
arr: ["a", "b", "c"]

Стек:        Куча:
arr ──────►  ┌─────────────┐
             │ 0: "a"      │
             │ 1: "b"      │
             │ 2: "c"      │
             │ length: 3   │
             │ __proto__ ──┼──► Array.prototype
             └─────────────┘                    │
                                                ▼
                              ┌─────────────────────────┐
                              │ map, filter, push...    │
                              │ __proto__ ──────────────┼──► Object.prototype
                              └─────────────────────────┘
```

### Откуда берутся методы массива

```js
const arr = [1, 2, 3];
arr.map(x => x * 2);  // откуда взялся map?
```

`arr` не имеет собственного свойства `map`. Но `arr.__proto__ === Array.prototype`, а там есть `map`. Это **прототипное наследование** — то, что ты изучишь в следующих уроках.

```js
console.log(Array.prototype.hasOwnProperty("map")); // true
console.log(arr.hasOwnProperty("map"));             // false
console.log(arr.__proto__ === Array.prototype);     // true
```

### Массивы можно "испортить", делая их похожими на объекты

```js
const arr = [1, 2, 3];
arr.foo = "bar";           // OK, но не делай так
arr["whatever"] = "oops";  // тоже OK

console.log(arr.length);   // 3 — не изменилось! Добавленные строковые ключи не считаются
console.log(arr.foo);      // "bar"
```

Почему `length` не изменилось? Потому что `length` считает только **числовые индексы** от `0` до `2^32 - 1`. Произвольные строковые ключи — это обычные свойства объекта, они не влияют на `length`.

### Сравнение массивов — по ссылке

```js
const a = [1, 2, 3];
const b = [1, 2, 3];
console.log(a === b); // false

const c = a;
c.push(4);
console.log(a); // [1, 2, 3, 4] — оригинал мутировал!
```

Те же правила, что и для объектов: `===` сравнивает ссылки, `const` не защищает от мутации, spread `[...arr]` создаёт поверхностную копию.

### Итерация по массиву через `for...in` — опасно

```js
const arr = ["a", "b"];
for (const key in arr) {
  console.log(key); // "0", "1" — а ещё и другие перечисляемые свойства!
}
```

`for...in` идёт по **всем перечисляемым свойствам**, включая унаследованные от прототипа (редко, но возможно) и произвольные свойства, которые кто-то добавил. Для массивов используй `for...of`, `.forEach()`, `for` с индексом или методы `map`/`filter`.

## Пример кода

### Проверка: массив vs объект

```js
const arr = [1, 2, 3];
const obj = { 0: 1, 1: 2, 2: 3, length: 3 };

console.log(typeof arr);  // "object"
console.log(typeof obj);  // "object"

console.log(Array.isArray(arr)); // true
console.log(Array.isArray(obj)); // false

// Методы массива не работают на объекте:
arr.map(x => x * 2);        // [2, 4, 6]
// obj.map(x => x * 2);     // TypeError: obj.map is not a function

// Но можно одолжить метод через call:
Array.prototype.map.call(obj, x => x * 2); // [2, 4, 6]
```

### Spread массива = spread объекта

```js
// Массив
const a = [1, 2];
const b = [...a, 3];  // [1, 2, 3]

// Объект
const o = { x: 1 };
const p = { ...o, y: 2 };  // { x: 1, y: 2 }

// Оба — поверхностное копирование
```

### Деструктуризация массива = извлечение по ключу

```js
const arr = ["a", "b", "c"];
const [first, second] = arr;
// то же самое, что:
const first = arr[0];
const second = arr[1];
```

## Частые ошибки

**Ошибка 1: Думать, что `typeof [] === "array"`**

В JavaScript нет типа `array`. Массивы — объекты. Проверяй через `Array.isArray()`.

**Ошибка 2: `for...in` по массиву**

```js
const arr = [1, 2];
Array.prototype.bad = "oops";
for (const key in arr) {
  console.log(key); // "0", "1", "bad"!
}
```

*Почему возникает:* `for...in` идёт по всей цепочке прототипов. Массивы — это объекты с прототипом.

**Ошибка 3: Добавление нечисловых свойств к массиву и ожидание, что `length` изменится**

```js
const arr = [1, 2];
arr.foo = "bar";
console.log(arr.length); // 2 — foo не считается
```
