# Модуль 03 — CSS база

**roadmap.sh:** [раздел CSS во frontend-roadmap](https://roadmap.sh/frontend#css)

CSS превращает сырой HTML в то, на что хочется смотреть. Этот модуль — фундамент. Как подключить стили, как выбрать нужные элементы селекторами, как работает каскад, box model и самое важное для вёрстки: Flexbox и Grid. К концу модуля ты сам сверстаешь адаптивный лендинг.

## Если ты пришёл из Figma

Этот модуль — **самая знакомая** для тебя часть курса. То, что в Figma называется auto layout, padding, gap, fill container — это и есть Flexbox/Grid в CSS, просто другими словами. Концептуально ты уже умеешь думать в раскладке, нужно только выучить нотацию.

Быстрый перевод по самым частым понятиям этого модуля:

| Figma | CSS | Где разбирается |
|---|---|---|
| Auto layout (horizontal/vertical) | `display: flex; flex-direction: row/column` | [[03.5-Flexbox]] |
| Spacing between items | `gap` | [[03.5-Flexbox]] |
| Padding | `padding` | [[03.4-Box-model-и-позиционирование]] |
| Distribute: space between | `justify-content: space-between` | [[03.5-Flexbox]] |
| Align: center | `align-items: center` (поперёк) или `justify-content: center` (вдоль) | [[03.5-Flexbox]] |
| Auto layout grid | CSS Grid (`display: grid`) | [[03.6-Grid-и-адаптив]] |
| Constraints (Top/Right/Bottom/Left) | `position: absolute` + `top/right/...` | [[03.4-Box-model-и-позиционирование]] |
| Frames на 1440 / 768 / 375 | media queries (`@media (min-width: ...)`) | [[03.6-Grid-и-адаптив]] |
| Fill container / Hug / Fixed | `flex: 1` / `width: fit-content` / `width: 320px` | [[03.5-Flexbox]] |
| Corner radius | `border-radius` | [[03.4-Box-model-и-позиционирование]] |
| Stroke | `border` | [[03.4-Box-model-и-позиционирование]] |

Полная таблица — в [[Словарь-Figma-в-код]]. Если по ходу модуля встретишь термин, который не понимаешь — почти наверняка он там есть.

## Что изучаем
- Подключение CSS и базовый синтаксис правила.
- Селекторы: тег, класс, id, атрибут, комбинаторы, псевдо-классы и псевдо-элементы.
- Каскад, специфичность, наследование. Как браузер решает, какое правило применить.
- Box model (content / padding / border / margin) и позиционирование (`static`, `relative`, `absolute`, `fixed`, `sticky`).
- Flexbox — главный инструмент для одномерной раскладки.
- Grid плюс медиа-запросы: двумерная раскладка и адаптив под мобильные.
