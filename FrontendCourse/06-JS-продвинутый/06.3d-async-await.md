# async/await как сахар над промисами

## Зачем это нужно

Promise с `.then` решают проблему callback hell, но цепочки всё равно требуют мыслить «в обратном порядке»: результат появляется в колбэке, а не там, где ты его запросил. `async/await` делает асинхронный код похожим на обычный пошаговый: ты пишешь `const data = await fetch(...)`, и читается это сверху вниз. Но под капотом — всё те же Promises и microtask queue.

> **Опорные концепты:** Promise, .then, microtask queue, event loop.

---

## Главное

### async function всегда возвращает Promise

```js
async function greet() {
  return "Привет";
}

const result = greet();
console.log(result); // Promise {<fulfilled>: "Привет"}
```

Даже если внутри `return "Привет"`, снаружи это Promise. Движок автоматически оборачивает результат.

### await «приостанавливает» функцию

```js
async function loadUser() {
  console.log("Начало");
  const response = await fetch('/api/user');
  const user = await response.json();
  console.log(user.name);
}

loadUser();
console.log("После вызова");
```

**Что происходит:**
```
1. Вызов loadUser() — создаёт Promise, начинает выполнение
2. console.log("Начало") → "Начало"
3. await fetch('/api/user'):
   - fetch возвращает Promise
   - loadUser приостанавливается
   - управление возвращается вызывающему коду
4. console.log("После вызова") → "После вызова"
5. Когда fetch resolve'ится:
   - продолжение loadUser ставится в microtask queue
   - выполняется: response = <результат fetch>
6. await response.json():
   - снова приостановка...
   - когда resolve'ится — продолжение в microtask queue
7. console.log(user.name)
```

**Диаграмма:**
```
async function loadUser() {
  [==== синхронный код ====]
  await fetch(...)        ← разрыв! остаток функции → microtask
  [==== продолжение ======]
  await response.json()   ← разрыв! остаток → microtask
  [==== конец ============]
}

В памяти:
  loadUser — не одна функция, а "разрезанная" на части.
  Каждый await создаёт новый Promise, который resolve'ится
  при завершении ожидаемого Promise.
```

### await и Promise — одно и то же

```js
// Эти два варианта эквивалентны:

// async/await
async function foo() {
  const a = await promiseA;
  const b = await promiseB;
  return a + b;
}

// Promise.then
function foo() {
  return promiseA.then(a => {
    return promiseB.then(b => {
      return a + b;
    });
  });
}
```

### Обработка ошибок: try/catch

```js
async function loadUser(id) {
  try {
    const res = await fetch(`/api/users/${id}`);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const user = await res.json();
    return user;
  } catch (err) {
    console.error("Не удалось загрузить:", err);
    return null;
  }
}
```

`try/catch` вокруг `await` ловит **любую** ошибку: rejected Promise, синхронный throw, или сетевой сбой. Это чище, чем цепочки `.catch`.

### Последовательно vs параллельно

```js
// Последовательно (медленно):
async function loadSequential() {
  const user = await fetchUser();      // 1 сек
  const posts = await fetchPosts();    // +1 сек = 2 сек всего
  return { user, posts };
}

// Параллельно (быстро):
async function loadParallel() {
  const [user, posts] = await Promise.all([
    fetchUser(),
    fetchPosts(),
  ]); // оба запускаются сразу = ~1 сек
  return { user, posts };
}
```

Ключевое правило: `await` внутри `Promise.all` — параллельно. `await` один за другим — последовательно.

## Пример кода

### Переписываем .then на async/await

```js
// Было:
function loadData() {
  return fetch('/api/data')
    .then(res => res.json())
    .then(data => process(data))
    .catch(err => console.error(err));
}

// Стало:
async function loadData() {
  try {
    const res = await fetch('/api/data');
    const data = await res.json();
    return process(data);
  } catch (err) {
    console.error(err);
  }
}
```

### Топ-level await (модули)

```js
// В ES-модулях можно await прямо в глобальном scope:
const data = await fetch('/api/config').then(r => r.json());
console.log(data.apiUrl);
```

### async в колбэках — осторожно!

```js
// Проблема:
[1, 2, 3].forEach(async (id) => {
  const user = await fetchUser(id);
  console.log(user.name);
});
console.log("Готово"); // выведется ДО пользователей!
```

`forEach` не ждёт await. Используй `for...of`:

```js
// Правильно:
for (const id of [1, 2, 3]) {
  const user = await fetchUser(id);
  console.log(user.name);
}
console.log("Готово"); // выведется после всех
```

## Частые ошибки

**Ошибка 1: Забыть await**

```js
async function foo() {
  const user = fetchUser(1); // забыли await!
  console.log(user.name);    // TypeError: user.name — user это Promise!
}
```

*Почему возникает:* без `await` переменная содержит Promise, а не результат.

**Ошибка 2: async без await — бесполезная обёртка**

```js
async function add(a, b) {
  return a + b; // нет смысла в async!
}
```

*Почему возникает:* функция синхронная, но возвращает Promise. Лишняя обёртка.

**Ошибка 3: Параллельность через await в цикле**

```js
// Медленно:
for (const id of ids) {
  await process(id); // каждый ждёт предыдущего
}

// Быстро:
await Promise.all(ids.map(id => process(id)));
```

**Ошибка 4: Не ловить ошибки в async-функциях**

```js
async function risky() {
  const res = await fetch('/api'); // может упасть
  return res.json();
}
risky(); // UnhandledPromiseRejection если fetch упадёт!
```

*Почему возникает:* async-функция всегда возвращает Promise. Если внутри ошибка и нет try/catch — Promise rejected, и нужен .catch снаружи.

### ✏️ Практика

**Задание 4 — Перепиши на async/await**

```js
function getUserAndPosts(userId) {
  return fetch(`/api/users/${userId}`)
    .then(r => r.json())
    .then(user => {
      return fetch(`/api/users/${userId}/posts`)
        .then(r => r.json())
        .then(posts => ({ user, posts }));
    });
}
```

**Задание 5 — Параллельная загрузка**

Напиши `loadDashboard()` через async/await, который параллельно загружает:
- `/api/user`
- `/api/notifications`
- `/api/stats`

И возвращает объект `{ user, notifications, stats }`. Обработай ошибку: если один упал, остальные всё равно должны загрузиться (используй `Promise.allSettled`).

**Задание 6 — Sleep через Promise**

Напиши `sleep(ms)` через Promise + setTimeout. Затем используй его:

```js
async function demo() {
  console.log("Начало");
  await sleep(1000);
  console.log("Прошла секунда");
  await sleep(2000);
  console.log("Прошло ещё две");
}
```
