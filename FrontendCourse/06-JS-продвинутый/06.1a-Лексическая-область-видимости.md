# Лексическая область видимости и scope chain

## Зачем это нужно

Прежде чем понять замыкания, нужно увидеть, как JavaScript ищет переменные. Когда внутри функции написано `console.log(x)`, откуда движок знает, какое `x` использовать? Ответ: он идёт по **цепочке областей видимости** (scope chain) — от текущей функции наружу, пока не найдёт переменную. Этот механизм лежит в основе всего: от простого доступа к глобальным переменным до сложных замыканий.

> **Опорные концепты:** функции, вложенные функции, переменные `let`/`const`/`var`.

---

## Главное

### Глобальная и локальная область

```js
const globalVar = "я глобальная";

function outer() {
  const outerVar = "я в outer";
  console.log(globalVar); // OK — видит глобальную
}

outer();
console.log(outerVar);    // ReferenceError — снаружи не видно
```

Переменная `let`/`const` видна только внутри `{}`, где объявлена. Это **блочная область видимости**.

### Вложенные функции видят наружу

```js
function outer() {
  const outerVar = "outer";

  function inner() {
    const innerVar = "inner";
    console.log(outerVar); // OK — inner видит наружу
    console.log(innerVar); // OK — своя переменная
  }

  inner();
  // console.log(innerVar); // ReferenceError — outer не видит внутрь
}

outer();
```

Функция видит переменные **своей** области и всех **внешних** областей. Но не наоборот.

### Scope chain — цепочка поиска

Когда движок встречает переменную, он ищет её так:

```
1. Текущая функция → есть? → используем
2. Нет → внешняя функция → есть? → используем
3. Нет → ещё внешняя → ...
4. Нет → глобальная область → есть? → используем
5. Нет → ReferenceError
```

**Диаграмма:**
```
Global Lexical Environment
+-----------------------------+
| Identifiers:                |
|   globalVar -> "global"     |
|   outer -> <function>       |
+-----------------------------+
        ▲
        │ outer's outer reference
        │
outer's Lexical Environment
+-----------------------------+
| Outer: Global               |
| Identifiers:                |
|   outerVar -> "outer"       |
|   inner -> <function>       |
+-----------------------------+
        ▲
        │ inner's outer reference
        │
inner's Lexical Environment
+-----------------------------+
| Outer: outer                |
| Identifiers:                |
|   innerVar -> "inner"       |
+-----------------------------+

Scope chain for console.log(outerVar) inside inner:
  inner → outer → global
```

### Почему это называется «лексическая» область

«Лексическая» означает: область видимости определяется **местом написания** функции в коде, а не местом вызова.

```js
const x = "global";

function outer() {
  const x = "outer";
  return function inner() {
    console.log(x); // какой x? Тот, что был виден при написании!
  };
}

const fn = outer();   // outer завершился
fn();                 // "outer" — а не "global"!
```

`inner` была написана внутри `outer`, поэтому её scope chain навсегда связан с `outer`.

### Call stack во время вызова

```js
function a() { b(); }
function b() { c(); }
function c() { console.log("c"); }

a();
```

**Диаграмма стека:**
```
Шаг 1 — вызов a():
+------------------------+
| a() execution context  |
+------------------------+

Шаг 2 — a() вызывает b():
+------------------------+
| b() execution context  |
| a() execution context  |
+------------------------+

Шаг 3 — b() вызывает c():
+------------------------+
| c() execution context  |
| b() execution context  |
| a() execution context  |
+------------------------+

Шаг 4 — c() завершился:
+------------------------+
| b() execution context  |
| a() execution context  |
+------------------------+

Шаг 5 — b() завершился:
+------------------------+
| a() execution context  |
+------------------------+

Шаг 6 — a() завершился:
+------------------------+
| (пусто)                |
+------------------------+
```

Execution context = лексическое окружение + this + другие служебные данные.

## Пример кода

### Простой scope chain

```js
const name = "Глобал";

function greet() {
  const greeting = "Привет";

  function say() {
    const emoji = "👋";
    console.log(`${greeting}, ${name}! ${emoji}`);
  }

  say();
}

greet(); // "Привет, Глобал! 👋"
```

`say` ищет `greeting` в своей области → не находит → идёт в `greet` → находит. Ищет `name` → не находит в `say` → не находит в `greet` → находит в глобальной области.

### Поиск переменной по цепочке

```js
let x = 1;

function a() {
  let x = 10;

  function b() {
    let x = 100;
    console.log(x); // 100 — своя переменная
  }

  b();
  console.log(x);   // 10 — переменная a
}

a();
console.log(x);     // 1 — глобальная
```

## Частые ошибки

**Ошибка 1: Думать, что функция видит переменные из места вызова**

```js
const x = "global";

function foo() {
  console.log(x);
}

function bar() {
  const x = "local";
  foo(); // "global", не "local"!
}
```

*Почему возникает:* интуиция говорит «foo вызвана внутри bar → видит bar». Нет. Область лексическая — определяется местом **написания**.

**Ошибка 2: Перекрытие (shadowing) без понимания**

```js
let name = "Иван";

function test() {
  let name = "Пётр"; // перекрывает глобальную
  console.log(name); // "Пётр"
}

test();
console.log(name);   // "Иван" — глобальная не изменилась
```

*Почему возникает:* кажется, что `let name` внутри функции изменяет внешнюю. Нет — создаёт новую локальную переменную.

**Ошибка 3: `var` и всплытие путают scope chain**

```js
function test() {
  console.log(x); // undefined, не ошибка!
  var x = 5;
}
```

`var` всплывает в начало функции, поэтому переменная существует, но без значения. Это не scope chain — это hoisting.

**Задание 1:**
```js
const a = 1;
function foo() {
  const b = 2;
  function bar() {
    console.log(a, b);
  }
  bar();
}
foo();
```

**Задание 2:**
```js
const x = "A";
function outer() {
  const x = "B";

    console.log(x);
  }
  return inner;
}
const fn = outer();
fn();
```

### ✏️ Практика

**Задание 3 — Нарисуй scope chain**

```js
const global = "G";
function level1() {
  const a = "L1";
  function level2() {
    const b = "L2";
    function level3() {
      console.log(global, a, b);
    }
    level3();
  }
  level2();
}
level1();
```

Нарисуй три уровня лексических окружений и стрелки outer reference.

**Задание 4 — Перекрытие и scope**

```js
let count = 0;

function increment() {
  let count = 10;
  count++;
  console.log("inside:", count);
}

increment();
console.log("outside:", count);
```

Предскажи вывод. Объясни, почему внешняя `count` не изменилась.
